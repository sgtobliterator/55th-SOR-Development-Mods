------------------------------------------------------------------------------------------------------------------------------------
  Garage Spawner with Dynamic Vehicle Loadouts

      by カツオ武士(P)  (Katsuobusi24)
------------------------------------------------------------------------------------------------------------------------------------

**************************************************************************************************************************************************************************
Description:
このスクリプトはビークルやパイロンウェポンを試したり練習ができるビークルスポナーです。
DCON's Multiplayer Vehicle Spawnerをベースに製作しています。

**************************************************************************************************************************************************************************
Features:
・SP/MPの両方で使用できます。
・MOD(CUP, RHS, Unsung etc...)のビークルでも使用できます。
・3DENエディターのDynamic Vehicle Loadoutとほぼ同等の機能が利用できるVirtual Garageをミッション内で開けるようになります。
・ヒットポイントのダメージ設定(特定のビークルでは不可)と部隊章の設定(現在FIR, USAF MODのみ)ができます。
・スポーン時の状態は"Only Spawn", "Get in", "Flying"から選択できます。
  (ただし"Flying"はヘリや飛行機のみ使用でき、それ以外のビークルでは"Get in"と同じになります。)
・ビークルと同時に選択したクルーもスポーンさせることができます。スポーンさせるユニットタイプは"kbf\GarageParameters.sqf"で指定できます。
・ミッション製作者は選択できるビークルの種類を指定できます。
・ホワイトリスト/ブラックリストの設定ができ、陣営ごとに個別のリストを使用できます。
・ビークルの設定陣営によってスポーンできるビークルを変更できます。(陣営設定はビークルのconfigでされています。)
・スポーン時に追加のコマンドを実行させることができます。
  デモミッションでは破壊されたまたは一定時間放置されたビークルを自動的に消すスクリプトを実行させています。

・ビークルをスポーンさせる場所はオブジェクトの位置で指定します。
・スポーンさせる場所には自動でマップ上に位置と影響範囲のマーカーが追加されます。表示名前はポイントの変数で指定できます。
・スポーンさせる場所の20m内に他のビークルがある場合と
　マルチプレイにおいて他人が同じ場所でガレージを開いている場合はガレージは開けないようになっています。
  (もしも誰も開いていないにもかかわらず開けなくなった場合は、"Reset Garage Flag"を使ってフラグをリセットしてください。)
・ビークルを消すアクションも同時に追加されます。ただし変数名を"DFV_名前"とすることでそのオブジェクトは消せなくなります。

**************************************************************************************************************************************************************************
Installation/Usage:
kbfフォルダとdescription.ext、init.sqfをミッションフォルダに入れる。
もしもdescription.extやinit.sqfが既にある場合は中身を既にあるものにコピーする。


スポナーを開くオブジェクトに以下を追加

Syntax
[this, spawn point object, spawnable types, enable sides, display distance, additional script] call kbf_fnc_garageInit;

Parameters
- this : thisのみ、変更しないこと
- spawn point object : Object - ビークルをスポーンさせる位置を指定するオブジェクトの変数名
- spawnable types : Array - 選択できるビークルの種類、["Auto"]の場合はスポナー位置の表面で決まる (オプション デフォルト ["Auto"])
                            使用できるタイプ : "All", "Auto", "Ground", "Car", "Tank", "Helicopter", "Plane", "Ship", "StaticWeapon"
- enable sides : Array - スポナーを選択できる陣営、["ALL"]の場合はどの陣営でも使用できる (オプション デフォルト ["ALL"])
                         使用できるタイプ : "ALL", "BLUFOR", "OPFOR", "INDEP", "CIV"
- display distance : Number - プレイヤー選択肢を表示させる距離(m) (オプション デフォルト 10)
- additional script : String - スポーン時に追加で実行するスクリプト(オプション デフォルト "")
                               使用できる変数: (_veh: スポーンするビークル(Object), _point: スポーンポイント(Object) など、残りはプログラムを直接見てください。)

Examples
[this, GP_Airport] call kbf_fnc_garageInit; //スポナー名: "Airport"、ビークルタイプ: "Auto"(スポナーの表面で決まります)
[this, GP_Airport_1, ["Car", "Tank"]] call kbf_fnc_garageInit; //スポナー名: "Airport 1"、ビークルタイプ: "Car", "Tank"(車両と戦車のみスポーン可能になります)
[this, GP_USS_Freedom, ["Ground"], ["BLUFOR"], 5] call kbf_fnc_garageInit; //スポナー名: "USS Freedom"、ビークルタイプ: "Ground"(船以外)、使用できる陣営: "BLUFOR"のみ、操作表示は処理を呼ぶオブジェクトから5mに制限されます。
[this, GP_USS_Freedom, ["Auto"], ["BLUFOR", "INDEP"], 10, "[] execVM 'yourscript.sqf'"] call kbf_fnc_garageInit; //スポーンする際に"yourscript.sqf"を実行します。
